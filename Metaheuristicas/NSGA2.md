# NSGA-II: Non-dominated Sorting Genetic Algorithm II

### ¿Qué es NSGA-II?
NSGA-II es un algoritmo evolutivo multiobjetivo utilizado para resolver problemas con múltiples objetivos.
Genera un conjunto de soluciones no dominadas que representan un equilibrio entre los diferentes objetivos.

### Conceptos clave

1. **Población**: Conjunto de soluciones posibles.
2. **Dominio**: Una solución A domina a una solución B si es mejor en al menos un objetivo.
3. **Clasificación de no dominancia**: La población se divide en frentes no dominados.
4. **Diversidad**: Asegura que las soluciones sean variadas.
5. **Operadores genéticos**: Selección, cruce y mutación.

### Funcionamiento básico de NSGA-II

1. **Inicialización**: Se genera una población inicial aleatoria de soluciones.
2. **Clasificación de no dominancia**: Se dividen las soluciones en frentes.
3. **Selección**: Se seleccionan los mejores individuos para reproducción.
4. **Cruce y mutación**: Generación de nuevas soluciones.
5. **Repetición**: El proceso continúa hasta alcanzar una condición de parada.

### Aplicaciones de NSGA-II

- Optimización en ingeniería.
- Optimización de recursos.
- Problemas en bioinformática.
- Diseño de sistemas complejos.

### Conclusión

NSGA-II es eficaz para encontrar soluciones balanceadas en problemas con múltiples objetivos. Es ampliamente utilizado en problemas de optimización real.
